# System Monitoring Script

A simple Bash script to track system health for the DevOps Capstone Project.

## What it does
* Checks **Disk Space** usage.
* Calculates **RAM Memory** percentage.
* Lists the **Top 5** memory-consuming processes.
* Logs timestamps and alerts to `Storage.log`.

## How to run it
```bash
chmod +x system-monitoring-script.sh
./system-monitoring-script.sh
```
